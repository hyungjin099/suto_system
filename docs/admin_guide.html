  • 고객은 거래처별 전용 주소로 접속해 주문하고, 지난 주문도 조회합니다.
  • 관리자는 이 관리자 페이지에서 주문을 확인·입력·수정·취소하고, 거래처·제품·별칭 등 기준 정보와 고객 화면 팝업을 관리합니다.
  • 스프레드시트는 접수된 주문이 일자별 시트에 기록되는 작업용 장부입니다. 기록된 뒤의 관계는 2장을 꼭 읽어 주세요.

2. 시스템과 스프레드시트의 관계

가장 중요한 규칙
주문이 스프레드시트에 기록되는 순간까지만 시스템이 시트에 넣어 줍니다. 그 뒤로는 시스템과 시트의 연결이 끊어집니다. 관리자 화면에서 한 수정·취소는 시트에 반영되지 않으므로 시트에서 직접 고치거나 지워야 하고, 반대로 시트에서 직접 고친 내용도 시스템 주문 내역에 반영되지 않습니다.

상황별 정리

상황시스템(관리자 페이지)스프레드시트
고객이 주문 페이지에서 주문자동 저장자동으로 기록됨
관리자가 [새 주문 추가]로 입력저장자동으로 기록됨
주문 내용 수정 (폭·길이·롤수·납품처 등)시스템에서만 변경시트에서 직접 수정해야 함
주문 취소취소 표시(이력은 남음)시트에서 직접 삭제해야 함
재단 완료 체크시스템에서만 표시해당 없음
거래처·제품·별칭·단가 변경이후 접수되는 주문부터 적용이미 기록된 행은 그대로
시트에서 직접 수정·삭제반영되지 않음시트만 바뀜
그래서 이렇게 운영하세요
  • 주문을 수정·취소했다면 작업자에게 바로 알려 시트를 고치게 하세요. 시스템과 시트의 내용이 달라질 수 있습니다.
  • 엑셀 다운로드와 주문 내역 화면은 시스템 기준입니다. 시트에서 한 수정은 거기에 나타나지 않습니다.

주문 접수 시간 규칙

언제고객 주문 페이지
주말, 공휴일"주문 접수 불가" 안내 화면이 나오고 주문할 수 없습니다.
매일 23:00 ~ 03:00접수 중단 시간입니다.
평일 03:00 ~ 18:00접수 즉시 시트의 오늘 시트에 기록됩니다.
평일 18:00 ~ 23:00접수는 되지만 시트에는 바로 넣지 않고, 다음 영업일 새벽 02시에 전송됩니다. 주문 내역의 시트상태에 DEFERRED로 보입니다.
  • 관리자가 직접 입력하는 주문은 시간 제한(주말·공휴일·23~03시)을 받지 않습니다. 18시 이후에 입력하면 마찬가지로 다음 영업일 02시에 시트로 전송됩니다.
  • 납품예정일: 13시 이전 접수는 다음 영업일, 13시 이후 접수는 그다음 영업일이 기본이며 주말·공휴일은 건너뜁니다. 주문 수정 창에서 납품예정일을 직접 입력하면 그 값이 우선합니다.
  • 시트 전송이 실패하면 시스템이 5분마다 다시 시도합니다(접수 후 24시간 이내까지).

3. 주문 내역

가장 자주 쓰는 화면입니다. 모든 주문을 품목(행) 단위로 펼쳐서 보여 줍니다.

용도이 화면에서 하는 일

  • 들어온 주문을 조회·검색하고, 시트 전송 상태를 확인합니다.
  • 전화·문자로 받은 주문을 직접 입력합니다.
  • 주문 내용을 수정하거나 취소합니다.
  • 재단 작업이 끝난 품목을 체크하고, 목록을 엑셀로 내려받습니다.

알림새 주문 알림

관리자 페이지가 열려 있으면 고객이 주문할 때마다 알려 줍니다. (관리자가 직접 입력한 주문은 알림이 가지 않습니다.)

  • 화면 오른쪽 위 카드: "📦 거래처명 …" 형태로 잠시 나타났다 사라집니다.
  • 사이드바 빨간 숫자: [주문 내역] 옆에 아직 확인하지 않은 새 주문 수가 표시됩니다.
  • 복귀 안내: 한동안 접속하지 않았다면 상단에 "마지막 접속 이후 N건의 새 발주가 있습니다 — 확인하기 / 나중에"가 나옵니다.
  • 바탕화면 알림: 처음 한 번 "새 발주 알림을 데스크톱 알림으로 받으시겠어요?"가 나오면 허용을 누르세요. 브라우저 설정에서 알림이 차단되어 있으면 오지 않습니다.
  • 탭 제목 깜빡임: 브라우저가 최소화되어 있으면 탭 제목이 깜빡입니다.
  • 알림·사이드바 숫자를 누르면 주문 내역으로 이동하고, 확인하지 않은 새 주문이 연한 초록색(왼쪽 초록 줄)으로 강조됩니다. 잠시 뒤 서서히 사라집니다.

  • 고객 화면의 [확인]은 그 방문 동안만 닫고, [다시 보지 않기]는 그 브라우저에서 해당 팝업을 숨깁니다. 제목이나 내용을 고치면 다시 보이므로 정정 공지는 수정해서 올리면 됩니다. 기기나 브라우저를 바꾸면 다시 보입니다.
  • 팝업은 로그인 전에도 거래처 주소로 조회될 수 있습니다. 단가·개인정보 같은 민감한 내용은 쓰지 마세요.
  • 주말·공휴일·23~03시처럼 접수 불가 화면이 나올 때와, 주문 내역 탭에서는 팝업이 뜨지 않습니다.

8. 원단 별칭 관리

용도이 화면에서 하는 일

거래처마다 주문할 수 있는 원단, 그 거래처가 부르는 이름(별칭), 적용 단가를 정합니다. 여기 등록된 별칭만 그 거래처의 주문 페이지 제품 목록(과 관리자 [새 주문 추가])에 나옵니다. 고객 화면에는 제품코드가 보이지 않고 별칭만 보입니다.

화면구성

영역설명
왼쪽: 거래처사용 중인 거래처 목록과 검색창. 거래처를 눌러 선택합니다.
가운데: 공식 원단 목록매입처별로 묶인 트리. 아직 이 거래처에 등록되지 않은 원단만 나오며, 사용 중인 원단만 보입니다. 검색(원단명·코드), 매입처 접기/펴기, 각 원단 체크박스, 위쪽 모두 선택과 등록 버튼이 있습니다. 모두 등록하면 "모든 원단이 매칭되었습니다"가 표시됩니다.
오른쪽: 이 거래처의 별칭이미 등록된 별칭 목록(원단별로 묶임)과 검색창. 각 별칭의 수정(연필), 삭제 버튼과 원단마다 + 별칭 추가 버튼이 있습니다.

흐름별칭 등록

왼쪽에서 거래처 선택
→
가운데에서 원단 체크
→
[등록]
→
오른쪽에 별칭 생성 (필요하면 수정)
  • 일괄 등록: 체크한 원단이 한꺼번에 등록됩니다. 별칭은 원단명, 단가는 원단의 공식 단가로 먼저 들어갑니다. 등록 후 "N건 등록 완료"가 나오고, 같은 별칭이 이미 있어 건너뛴 건은 사유와 함께 표시됩니다(처음 몇 건만 보이고 나머지는 "외 N건").
  • 별칭 수정: 오른쪽 별칭의 연필 아이콘 → 별칭과 단가를 고치고 ✓로 저장합니다.
  • 별칭 추가: 같은 원단에 별칭을 더 만들 수 있습니다(예: A-1, A-2를 단가를 다르게 두고 따로 운영). 원단 아래 + 별칭 추가 → 새 별칭·단가 입력 → ✓.
  • 별칭 삭제: 휴지통 아이콘 → 확인창. 그 별칭의 단가 정보도 함께 사라지며 되돌릴 수 없습니다.

주의알아 둘 점

  • 한 거래처 안에서 같은 별칭 이름은 둘 이상 쓸 수 없습니다. (같은 원단이라도 이름이 다르면 여러 개 가능)
  • 단가는 0 이상의 숫자여야 합니다.
  • 별칭이나 단가를 바꾸거나 삭제해도 이미 접수된 주문에는 접수 당시의 별칭·단가가 그대로 남습니다. 삭제된 별칭은 이후 주문·재주문에서 선택할 수 없습니다.
  • 고객이 "원하는 원단이 목록에 없다"고 하면 대부분 이 화면에서 별칭이 등록되지 않은 경우입니다.

14. 매일 점검 · 자주 발생하는 문제 · 연락처

매일 영업 시작 전 점검

  1. [주문 내역]에서 시트상태 선택을 전송실패로 놓고 남아 있는 주문이 없는지 확인합니다. 있으면 개발자에게 연락합니다.
  2. 어제 18시 이후 접수된 주문(DEFERRED)이 오늘 02시에 전송되어 전송완료로 바뀌었는지 확인합니다.
  3. 스프레드시트에 오늘 날짜 시트가 만들어졌는지 확인합니다. 안 보이면 오전 9시 이후에도 확인하고, 그래도 없으면 시트 메뉴 [주문관리] → [오늘 탭 만들기]를 실행합니다.
  4. 수정·취소한 주문이 있다면 작업자에게 전달했는지 확인합니다.
  5. 끝난 공지 팝업이 있으면 [팝업 관리]에서 정리합니다.

자주 발생하는 문제

문제확인 · 조치
관리자 로그인이 안 됨아이디·비밀번호 확인 → 크롬 시크릿 창(Ctrl+Shift+N)에서 시도 → 되면 원래 창에서 Ctrl+Shift+R(강제 새로고침). 일반 관리자는 admin에게 비번 초기화 요청. 그래도 안 되면 개발자 연락.
주문은 들어왔는데 시트에 안 보임주문 내역의 시트상태 확인. 미전송이면 몇 분 대기, DEFERRED면 다음 영업일 02시 전송이 정상, 전송실패면 개발자 연락. 반기 전환 시기라면 [시스템 설정]의 URL이 새 반기 칸에 등록됐는지도 확인.
새 주문 알림이 안 옴관리자 페이지가 열려 있고 로그인 상태인지, 브라우저 알림 권한이 "허용"인지 확인. 관리자가 직접 입력한 주문은 알림이 가지 않는 것이 정상.
고객이 "주문이 안 된다 / 접수 불가"라고 함주말·공휴일·23~03시인지 확인(2장). 급하면 관리자가 [새 주문 추가]로 직접 입력.
고객 제품 목록에 원하는 원단이 없음그 거래처에 별칭이 등록되어 있는지 [원단 별칭 관리]에서 확인. 원단 자체가 미사용으로 되어 있지 않은지는 [제품 관리]에서 확인.
고객 주문 내역에서 주문이 안 보임기본 조회 기간이 "이번 주"입니다. 기간을 넓혀 보도록 안내. 관리자가 취소한 품목은 고객에게 보이지 않는 것이 정상.
시스템과 시트의 내용이 다름수정·취소는 시트에 자동 반영되지 않습니다(2장). 시스템 기준으로 시트를 직접 맞추세요.
"안전하지 않음" 경고HTTPS 인증서 갱신 문제일 수 있음 → 개발자 긴급 연락.
사이트가 안 열림인터넷 연결과 다른 사이트를 먼저 확인 → 정상이면 시스템 장애 → 개발자 긴급 연락.
공공데이터 인증키 만료 메일이 옴공휴일 자동 갱신에 쓰는 키입니다. 새 키를 발급받아 시트 메뉴 [주문관리] → [공공데이터 인증키 설정]에서 바꿉니다. 모르면 개발자에게 전달.
