주문 관리 시트 사용 가이드

작업자용 매뉴얼
드림컴퍼니 주문 자동화 시스템

1. 시스템 개요

이 스프레드시트는 고객 주문을 자동으로 받아 매일 날짜별 시트에 정리해주는 도구입니다. 시트에 올라오는 데이터는 모두 주문 관리 시스템에서 자동으로 전송된 내용입니다.

하루 흐름 요약

00시 → 오늘 날짜의 새 시트 자동 생성 01시 → 어제 완료 못한 주문이 오늘 시트로 자동 이월 02시 → 어제 17시 이후 접수된 주문이 오늘 시트에 추가 낮 → 신규 주문이 접수되는 대로 오늘 시트에 자동 입력

2. 시트 종류 안내

시트 이름설명
지역코드거래처별 지역(A/B/C) 매핑 정보
재단취합오늘 짜야 할 작업 모아보기
오늘_MM-dd(요일)오늘 날짜 시트 (접두어 "오늘_"로 구분)
MM-dd(요일)과거 날짜 보관 시트
양식, 공휴일시스템용 (건드리지 마세요)

오늘_ 접두어가 붙은 시트가 오늘 작업할 시트입니다. 날짜가 바뀌면 접두어가 자동으로 떨어지고 새로운 오늘 시트가 만들어집니다.

3. 매일 자동으로 일어나는 일

00시 — 오늘 시트 생성

  • 전날 "오늘_" 시트는 접두어가 떨어지고 보관 시트가 됨
  • 오늘 날짜의 새 "오늘_" 시트가 세 번째 위치에 생성됨
  • 주말·공휴일에는 생성되지 않음

01시 — 어제 미완료 주문 이월

  • 어제 시트에서 작업내용이 "짜는 중"이거나 비어 있는 행이 오늘 시트로 자동 복사됨
  • 복사된 행은 어제 시트에도 그대로 남지만, 더 이상 시스템이 관리하지 않음
  • No는 오늘 시트 기준으로 1부터 다시 매겨짐

02시 — 어제 17시 이후 주문 추가

  • 전날 17시 이후 접수된 주문은 접수 시점에 바로 시트에 쓰이지 않고, 이 시간에 일괄 입력됨
  • No는 기존 번호 뒤에 이어서 매겨짐

낮 시간 — 실시간 주문 입력

  • 고객이 주문을 등록하면 몇 초 이내에 오늘 시트에 자동 추가됨
  • 13시 ~ 17시 사이 주문은 셀 배경이 연한 파란색으로 표시 (오후 접수 구분용)

4. 시트 컬럼 안내

열이름설명
ANo제품 단위 구분 번호
B주문번호시스템이 발급한 고유 번호
C발주일주문이 접수된 시각
D제품코드
E제품명
F작업내용작업자가 수정 (예: "짜는 중" → "완료")
G/H/I폭 / 길이 / 롤수
J발주처주문한 거래처
K납품처배송 받을 곳
L출고작업자가 수정
M비고작업자가 수정
N납품예정일
O/P/Q확인1/2/3작업자가 체크

같은 주문에서 같은 제품이 여러 규격이면 A/B/C/D/E/J/K 열이 세로로 병합되어 보기 쉽게 묶입니다.

5. 재단취합 시트 사용법

데이터 로드

  • "오늘_" 시트에서 작업내용이 "짜는 중" 또는 비어있는 행만 자동으로 불러옴
  • 상단에서 "짜는중" 선택 시 전체, 특정 제품코드 선택 시 그 제품만

작업내용 저장

  1. "현재 작업내용" 열(D열)에서 각 행의 작업 상태를 수정
  2. "작업내용 저장" 버튼 클릭
  3. 수정된 내용이 오늘_ 시트의 작업내용 열(F)에 자동 반영됨

메뉴 설명

  • 현재 취합 새로고침 — 재단취합 화면 다시 그리기
  • 제품목록 새로고침 — 상단 드롭다운 제품코드 목록 갱신
  • 작업내용 저장 — 수정한 작업내용을 원본 시트에 저장
  • 취합 화면 초기화 — 재단취합 시트 전체 초기화 (주의)

6. 시트에서 할 수 있는 것

  • 오늘 시트의 F(작업내용), L(출고), M(비고) 열 수정
  • 오늘 시트의 O/P/Q(확인) 체크박스 체크
  • 재단취합 시트에서 작업내용 수정 후 "작업내용 저장" 반영
  • A(No) 열 수정 — 주의 표기(999, 0) 등 작업자 관례대로
  • 행 분할 — 롤수가 많을 때 한 행을 여러 행으로 쪼개서 작업
  • 셀 병합 재조정 — 행 분할 후 다시 병합하거나 필요에 따라 병합 풀기
  • 열 숨기기 — 보기 편하게 필요 없는 열은 숨겨도 됨
  • 과거 시트에서 완료된 주문 참고 열람
  • 완료된 과거 날짜 시트 수동 삭제 (탭 우클릭 → 시트 삭제)
  • 자동 입력된 주문 데이터의 수정·삭제
    ⚠️ 단, 반드시 관리자에게 공유해서 시스템에도 동일하게 수정·삭제되도록 해야 함

7. 시트에서 하지 말아야 할 것

1) 신규 주문을 시트에 직접 입력하지 마세요

  • 전화 주문 등 신규 주문은 관리자가 시스템에서 등록합니다
  • 시트에 직접 쓴 신규 주문은 시스템에 저장되지 않고, 재단취합·이월에서 누락됩니다

2) R열(행ID)을 절대 수정하지 마세요

  • R열은 각 주문 품목을 구분하는 시스템 고유 번호입니다
  • 숨김 처리되어 있지만 값을 바꾸거나 지우면:
    • 재단취합의 "작업내용 저장"이 엉뚱한 행에 저장되거나 작동 안 함
    • 전날 미완료 이월이 중복 복사되거나 누락됨
  • R열은 보이지 않게 두고 절대 건드리지 마세요

3) 자동 입력된 주문 데이터를 수정·삭제했을 때는 반드시 관리자에게 공유하세요

  • 수정·삭제 자체는 가능하지만, 시스템 DB에는 자동으로 반영되지 않습니다
  • 관리자가 시스템에서도 동일하게 처리해야 매출 집계·히스토리가 맞춰집니다

4) 양식, 공휴일, 지역코드 시트는 건드리지 마세요

  • 시스템 운영에 필수적인 시트입니다

5) "오늘_" 접두어를 임의로 바꾸지 마세요

  • 접두어는 00시에 자동 관리됩니다
  • 수동으로 바꾸면 재단취합이 오늘 시트를 못 찾습니다

8. 중요 안내 — 시스템과 시트의 연동 범위

[고객 주문 접수] → [시스템] → [시트에 자동 입력] ↓ 여기까지만 자동입니다 ↓ 이후 시트에서 하는 작업은 시스템과 연동되지 않습니다
  • 주문 데이터의 수정·삭제는 시스템에 자동 반영되지 않습니다
  • 주문 내용을 시트에서 수정·삭제한다면 반드시 관리자에게도 내용 공유해주세요
  • 작업자는 F(작업내용), L(출고), M(비고), O/P/Q(확인) 네 가지에만 집중하면 됩니다

9. 관리자 연락이 필요한 경우

  • 자동 입력된 주문 데이터 수정이 필요할 때
  • 자동 입력된 주문 행을 삭제해야 할 때
  • 00시가 지났는데 새 시트가 안 만들어졌을 때
  • 02시가 지났는데 어제 17시 이후 주문이 안 들어왔을 때
  • 재단취합이 작동하지 않을 때
  • 기타 시스템 오류로 보이는 상황
